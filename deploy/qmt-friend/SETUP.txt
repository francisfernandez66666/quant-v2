2026-11-04 的三条更正（比上面任何一段都新，先读这段）
------------------------------------------------------
1) 券商 11-05 起关闭 QMT 内置策略的一切本地文件读写与外部网络连接，并且 QMT 终端不许跑在
   公有云/虚拟机上。本包与 QMT 之间原来那条"策略读写本地文件"的桥**会整条退役**，
   所以本包的通道形态正在重定；在运营明确通知之前，**仍然不要发给朋友、不要装**。
2) 本地执行器（local_executor.py）的交易腿**缺省是关的**：它原本走 xtquant.xttrader，
   而那就是券商 9 月已经关闭的 miniQMT 独立交易通道；10-29 还有一次实录——反复重连会在
   QMT 客户端的共享内存里占 writer 槽，槽满直接把客户端拖崩。所以现在跑它只会得到
   `broker not available: xt_channel_disabled`（`params.xt_channel_enable` 不设＝不碰这条腿）。
   **不要为了"看看通不通"去打开它**：那条连接不是只读探测。
   11-05 之后合法的自动下单只有一条路：QMT 内置策略（沙箱内 passorder），也就是本包放进
   策略目录的那个文件；本地那份进程只做三件事——自证版本与阈值、算规则记影子、
   把客户端导出的读数 POST 回决策机。
3) 载体里烘进去的阈值不再是人手抄的：它们由 `scripts/derive_carrier_params.py --write`
   从 Go 的出厂默认单点导出（11-04 落地）。所以**别在机器上直接改 local_executor_params.json
   里的数**——改了下一轮就会被导出结果覆盖，而且没有任何东西会响。要改阈值，改 Go 那一处。

这个包做什么
------------
它把"在你这台 Windows 上跑起属于你自己的那一根交易执行腿"需要做的事串成一次双击：
校验包内文件（MANIFEST 逐文件 SHA256）→ 检查 Python 与 QMT 客户端 → 落网关代码 →
落两份载体产物 → 把桥文件与沙箱策略放进 QMT → overlay（VPN）→
装填（把你那把网关钥匙登记两处）→ 注册五个计划任务 → 起一次并自证。
（第五个是 11-05 新加的 QMTF-Carrier-Update：每天 15:40 让这台机器自己去问决策机
 "我该跑哪一版规则"，拿到新版就校验哈希后更新并回报；缺 Python 或缺更新器时它拒绝注册，
 因为注册一个空跑的任务比不注册更坏。）

本包**确实带有全量量化交易规则 + 沙箱策略 py + 一键解压/装载**（11-04 发版前补齐）：
- 五个规则模块 rules_form.py / rules_ladder.py / rules_factor.py / rules_t.py / rules_sizing.py；
- 参数真源 local_executor_params.json，以及它的单点导出器 derive_carrier_params.py；
- 两份**构建期烘好的产物**（不是空模板）：payload\artifacts\local_executor_<版本>.py 与
  payload\artifacts\qmt_internal_strategy_<版本>.py。后者就是 11-05 之后 QMT 沙箱内置策略
  （唯一合法自动下单形态，builtins 的 passorder，零本地文件读写、零外部网络）——五个规则
  模块与烘好的阈值都逐字内联在这两份产物里；仓里同名的两份只是模板，只供包内复现构建用；
- 可复现构建器 build_local_executor.py（连同它读的模板、handler/store 状态词表真源一起在包内），
  回报腿 report_uplink.py、载体更新轮询 carrier_updater.py、三段自证的更新脚本
  update_qmt_strategy.ps1 / update_local_executor.ps1 / update_local_executor.bat、
  看门狗 watchdog.ps1，以及本地执行器安装器 install_local_executor.ps1。
出包时已从 zip 解压到临时目录、在**包内**重跑构建器，两份产物逐字节 + SHA256 复现一致；
包内 MANIFEST.json 给每个文件记了 SHA256，装的时候第 1 步逐文件核对，对不上直接 ABORT。

包里**没有**、也永远不会有的东西
--------------------------------
- 你的券商账号密码：它只在你自己的 QMT 客户端里输入，从不经过这个包（这是硬规矩）。
- 任何账本或历史成交：包只带代码；你的成交账记在你机器的 data.db 里，重装/升级都不覆盖它。
- 网关钥匙：装填那一步由你**当场粘贴**运营给你的那一把，只进本机配置，不进命令行、不进日志。

开始之前请先准备好这五样
------------------------
1) 东莞证券 QMT 实盘交易端已经装好（本包不代装，检测不到就直接停）。
2) Python 3.11 或 3.12（本包不代装，检测不到会告诉你缺什么；网关只用标准库，不需要 pip 装任何东西）。
3) 量仔平台的用户名和登录口令（运营给你开的那个账号，权限位是"量化交易"）。
4) 网关钥匙（运营签发的一串，只有你这一把）。
5) overlay 的隧道配置文件（运营发给你，放进 C:\ProgramData\WireGuard\Tunnels\ 这个目录）。

怎么装（一键解压 / 装载）
------------------------
1) 用资源管理器打开本 zip，点"全部提取"解压到任意目录（这一步就是"一键解压"；包体在
   解压出的 payload\ 里，入口是 payload\tools\install_entry.bat）。
2) 双击 install_entry.bat，跟着问句走。看到最后一行
    LEG_INSTALL=PASS commit=… contract_fp=… overlay=… tunnel=…
就算装成。任何一步不过都会打
    LEG_INSTALL=ABORT step=N reason=…
然后**停下不动**——不会出现"装了一半看起来也在跑"那种状态。

纪律（写死在脚本里，不是愿望）：
- 缺省只预览：命令行直调 install.ps1（不带 -Apply）只打印完整计划，不答问题、不写任何字节；
  真正落码只由 install_entry.bat 传 -Apply 触发。
- 动手前先逐文件核对 MANIFEST 的 SHA256；产物数量不对、产物覆盖后哈希对不上、任何一步
  不过都 ABORT 并停下，已写的部分保留现场、不假装没动。
- 想先验包、不装：在构建机上跑 build_friend_package.sh --check <本 zip>，只读、不落盘、
  不改任何字节；绿了打 CHECK_OK files=… artifacts=2，篡改一个字节必转红。
- 出包时的可复现自证：把 zip 解到临时目录、在包内重跑构建器，两份产物逐字节比对；
  复现不上就删包不出包（ABORT 不留半态）。这些都在构建机跑，你不用做。

装完还有一件事要你亲手做（软件做不到）
--------------------------------------
在 QMT 客户端里新建/挂载模型策略，文件已经放在
    <QMT 安装目录>\python\新建策略文件.py
（这一步是 QMT 自己的交互流程，没有任何外部程序能替你点。）
QMT 的 python 目录里另外放了本包新带的 qmt_internal_strategy.py ——就是那份含全量规则的
沙箱策略产物，11-05 之后唯一合法的自动下单形态。**挂哪一份、怎么挂等运营通知**：通道形态
正在重定，在运营明确通知之前本包仍按最上面三段 11-04 更正办：**不要发给朋友、不要装**。
挂好以后，交易日 08:40 计划任务会自动把客户端与网关拉起来；15:30 起会自己判断"今天能不能关 QMT"，
判不过会留原因，**不要手工硬关**。

装了但不对（先看这三行，别翻闸门）
----------------------------------
- 最后一行是 LEG_INSTALL=ABORT step=7 reason=enroll_not_ok
  → 装填没过。最常见是钥匙粘错一位、或平台口令不对。重来一次即可（前面的落码不会重复破坏什么）。
- 页面/群里报"远端执行腿不可达"（值=2）
  → 先看这台机器是否开机、QMT 与网关进程是否在、overlay 是否通；网关本机访问
    http://127.0.0.1:8789/health 看 contract_ok 与 broker_connected。
- 报契约不符（只报不接单：下单会被拒，但健康线正常）
  → 这台机器的代码版本与广州对不上，重跑本包（同一版本 zip）即可；不要改配置来"绕过去"。

换机 / 重装 / 卸载之前
----------------------
先双击 export_ledger.bat 导出当日账本（它会先做完整性检查，检查不过拒绝导出）。
卸载双击 uninstall_entry.bat：先看预览，再打 YES 才动手；**默认保留 data.db 与日志**——
那是你的成交证据，不是一堆垃圾文件。

一句话原则
----------
这个包只做"把已有脚本按顺序跑一遍并逐步判过"，所有业务判定都仍由网关自己那套出厂档判据出。
它不会、也不允许出现"脚本里再抄一份规则"的情况——那份规则一旦和网关漂开，表现就是"看起来合规、
账记到别人名下"。
